## 2. 확장성 — 6.5 / 10

### 2.1 강점

1. **플러그인 리스트형 확장점 2개가 실제로 작동한다.** `LocationSimulationScheduler:22` 가 `List<LocationSource>` 를, `NotificationCommandServiceImpl:29` 가 `List<NotificationSender>` 를 전량 주입받아 순회한다. 구현체 파일 하나를 추가하면 호출부 수정이 **0**이다. `reference.md` §5·§16 이 요구한 OCP 를 만족하는 유일한 두 축이다.
2. **이벤트 발행 파이프라인이 규약 기반이다.** 도메인 서비스는 `ApplicationEventPublisher` 만 호출해 Kafka 를 모르고(§12 준수), `TransactionalDomainEventRelay:24-27` 이 `AFTER_COMMIT` 에서만 릴레이하며(DB 롤백 시 미발행), `KafkaEventPublisher:39-42` 가 클래스명 → 케밥케이스로 토픽을 유도한다. **새 이벤트를 추가할 때 등록할 레지스트리·설정 파일이 아예 없다.**
3. **모듈 경계가 살아 있다.** tokensave `acyclicity = 1.0`(순환 의존 0), `modularity = 0.98`. 엔티티 대부분이 다른 도메인을 FK 가 아닌 `Long id` 로 참조한다.

### 3.4 깨진 쪽 — 4건이 하나의 경로에 몰려 있다

가장 중요한 발견은 **개별 위반이 아니라 그것들이 한 줄에서 만난다는 점**이다.

**A. Java 25 toolchain 자동 다운로드 미설정 [상] — 시작조차 못 한다**
`backend/settings.gradle` 내용 전체가 `rootProject.name = 'backend'` 한 줄이다(직접 확인). foojay-resolver 도 `toolchainManagement` 블록도 없다. Gradle 9.5.1 은 명시 설정 없이 toolchain 을 내려받지 않으므로, JDK 21 만 깔린 개발자는 첫 `./gradlew` 에서 `No matching toolchains found for requested specification: {languageVersion=25 … auto-download false}` 를 만난다.
CLAUDE.md 의 *"Java 25(toolchain 고정)"* 이라는 표현은 오히려 **"toolchain 이 알아서 받아준다"는 오해**를 유도한다. 해결책은 `settings.gradle` 한 줄인데 없다. (이 머신에는 JDK 25 가 깔려 있어 현재 사용자는 이 문제를 겪지 않는다 — 그래서 발견되지 않은 채 남아 있다.)

**B. 적용 완료된 Flyway 마이그레이션이 in-place 로 수정돼 있다 [상]**
직접 확인한 커밋 이력: `24887af`(Flyway 도입) → 12일 뒤 `fe9032d`(BE-1)가 **`V1__init_schema.sql` 을 다시 수정**했다. `V2`·`V5` 도 사후 수정됐다. `application.yml` 의 flyway 블록에는 `validate-on-migrate` 설정이 없어 **기본값 true** 다.
이는 **CLAUDE.md 자신의 규칙(*"기존 `V1__init_schema.sql` 수정 금지"*)을 정면으로 위반**한다. 증상: `docker compose stop/start`(CLAUDE.md 가 "데이터가 유지된다"고 명시한 경로)로 쓰던 개발자가 `git pull` 후 부팅하면 `FlywayValidateException: checksum mismatch for migration version 1` → **앱이 아예 뜨지 않는다.**

`backend/.env.example` 은 실재하고 내용도 충실하나 CLAUDE.md·`docs/README.md`·`PROJECT_MASTER_PLAN.md` 어디에도 "복사해서 쓰라"는 안내가 없다. 배차 API 가 500 으로 죽고 나서야 `build.gradle` 주석에서 이유를 발견하게 된다.

### 4.5 디버깅 — 이 축에서 가장 약한 부분

## 7. ※ 미확인 — 검증하지 못한 항목
