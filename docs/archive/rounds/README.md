## 읽는 법

1. **번호로 찾는다** — 옛 절 번호(8.45 등)는 위 표의 범위로 파일을 고르고 그 파일의 같은 번호 머리글(`## 8.45 …`)을 연다. 머리글은 원문 그대로다.
2. **Ruling 번호로 찾는다** — 본문 `docs/IMPLEMENTATION_PLAN.md` 의 **§11 Ruling 색인**에서 번호 → 기록 위치를 본다(번호 하나당 한 행).
3. **문서 그래프로 찾는다** — `python3 ~/.claude/tools/docgraph/query.py <repo> ruling <N>` · `section <문서> <번호>` (`<문서>` 는 파일 이름, 예 `be-rounds-r5-r14 8.9`). 색인 대상은 `.docgraph/config.json` 의 `docs_globs` 에 `docs/archive/rounds/be-*.md` · `docs/archive/rounds/fe-*.md` 로 들어 있다(이 README 는 색인 밖).

## 규칙

- **원문은 고치지 않는다.** 다만 **절 인용 문자열**은 새 경로로 갱신돼 있다(옛 계획서 본문 경로로 적힌 8.45 인용 → `docs/archive/rounds/be-rounds-r22-r41.md` 의 같은 번호 꼴) — 옮긴 뒤 깨진 참조를 0건으로 유지하려는 조치이고, 바뀐 줄은 이동 작업 커밋 메시지에 건수와 함께 적혀 있다.
- 각 파일 머리의 "옮긴 절 · 기간" 표 아래부터가 원문이다. 원문 안의 "위" · "아래" · "이 문서" 는 옮기기 전 문서 기준이다.
- 새 기록은 여기에 쓰지 않는다 — 본문 계획서 끝에 새 절을 더하고, 끝나면 이 폴더로 옮긴다.
