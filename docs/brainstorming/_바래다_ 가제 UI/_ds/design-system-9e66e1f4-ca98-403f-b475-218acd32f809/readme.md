# 바래다 (BARAEDA) 디자인 시스템

> 바래다주지 못하는 날에도, 바래다준 것처럼.

바래다는 **학원 통학버스 통합관리 서비스**입니다. 학원 통학버스의 노선 편성, 학생 승하차,
학부모 안내, 차량·운행인력 관리를 하나의 시스템으로 묶어 통학버스 운영의 안전성과 효율성을 높입니다.
브랜드 한 줄은 "잘 탔고, 잘 내렸습니다" — 아이가 버스에 오르는 순간부터 학원 문을 들어서는 순간까지,
부모가 볼 수 없는 시간을 부모의 눈앞에 옮겨 놓는 것이 제품의 목적입니다.

※ 서비스명 "바래다"는 워킹 타이틀입니다.

## CONTENT FUNDAMENTALS — 카피는 이렇게 씁니다

**기본형: 짧고 단정한 존댓말. 사실을 먼저 말합니다.**

- **결론부터, 누가 → 무엇을 → 언제 → 어디서.**
  "하준이가 8:37에 한화아파트 정류장에서 승차했어요"
- **시간과 위치는 항상 구체적으로.** "곧 도착" ✗ → "약 5분 후 도착" ✓ /
  "잠시 후" ✗ → "정류장 도착 예정 시간은 8:45입니다" ✓
- **문제 상황일수록 차분하게, 다음 행동을 함께.**
  "수민이가 아직 승차하지 않았어요. 정류장 도착 예정 시간은 8:45입니다." + [기사에게 연락]
- **아이는 이름 + 이/가**("하준이가"), 어른은 역할 + 이름("동승 매니저 김윤정", "기사 박정호").
- **호차 표기는 숫자-숫자호차**("3-2호차"). 시각은 24시간제 콜론("8:37", "20:14").
- **어미**: 알림은 "-했어요 / -합니다" 혼용. 사실 통보는 "-했어요", 예정·설명은 "-합니다".
- **버튼 라벨은 동사로 끝냅니다**: "오늘 운행 보기", "기사에게 연락", "지연 알림 전송", "나중에".
- **화자**: 서비스는 자기를 드러내지 않습니다. "저희가" 대신 문장의 주어는 아이 또는 버스.
  사용자를 부를 때는 "보호자님"이 아니라 문장 자체를 무주어로 둡니다.

**이렇게 쓰지 않습니다**
- 느낌표 남발, 이모티콘, "~^^" 같은 가벼운 말투 → **이모지는 어디에도 쓰지 않습니다.**
- 불안을 키우는 표현: "미탑승 발생!! 지금 바로 확인하세요!"
- 모호한 표현: "잠시 후", "조금 늦어요"
- 광고식 과장: "업계 최초", "혁신적인"

**케이싱**: 한글이 기본. 영문은 브랜드 표기 `BARAEDA`(대문자, 자간 0.18em)와
제품 라벨(`PARENT · STUDENT APP`)에만 씁니다. 문장 안 영문 대문자 강조는 쓰지 않습니다.

**빈 상태·에러도 같은 규칙**: "오늘 운행이 아직 시작되지 않았어요 / 등원 운행은 8:10에 시작됩니다."
"코드가 맞지 않습니다. 학원 데스크에 문의해 주세요."

## VISUAL FOUNDATIONS

### 색 — 화이트 셸

**그린은 크롬(헤더·사이드바)에서 내려왔습니다.** 모든 면이 초록이면 무엇을 눌러야 하는지가
보이지 않기 때문입니다. 화이트 셸 규칙:

1. **크롬은 색이 아니라 선**입니다 — 헤더·사이드바는 오프 화이트(`--surface-chrome`) +
   1px `--border-chrome`. 다크에서는 딥 셰이드 `#16211D`.
2. **그린은 액션과 "정상"에만** — 주요 버튼, 승차 완료·정상 운행 상태, 선택된 내비 항목.
   화면에서 가장 강한 색은 항상 "지금 눌러야 할 곳" 하나입니다.
3. **위계는 색이 아니라 잉크 대비와 여백**이 만듭니다. 본문 잉크는 `#0F1D18`,
   보조는 `#5C665F`.
4. 브랜드 그린 면이 크게 나오는 곳은 **로그인 스플래시 한 곳**뿐입니다.
5. 흰 배경 위 글자로 쓰는 앰버·레드는 어둡게 조정합니다 — `--amber-ink #C77E12`,
   `--red-ink #C93F2C` (대비 4.5:1 이상). 지도 버스 마커처럼 **면**으로 쓸 때는
   원래 `#F5A623`을 그대로 씁니다.

권장 비율: **중립 면 74 / 미스트 18 / 그린 6 / 앰버+레드 2.**

| 이름 | HEX | 역할 |
| --- | --- | --- |
| 바래다 그린 | `#1F5C4D` | 헤더, 주요 버튼, 로고, 승차 완료·정상 운행 |
| 미스트 그린 | `#E8F0EC` | 서브 배경, 카드, 알림 목록·타임라인 바탕 |
| 오프 화이트 | `#FAFAF7` | 크롬 면 — 헤더·사이드바 |
| 페이지 틴트 | `#F4F5F2` | 본문 바탕 (크롬과 반 단계 차이로 구분) |
| 잉크 | `#0F1D18` | 본문 텍스트 — 위계의 주된 수단 |
| 버스 앰버 | `#F5A623` | 버스 마커·면. 글자는 `--amber-ink #C77E12` |
| 시그널 레드 | `#E05C4B` | 경고 면. 글자는 `--red-ink #C93F2C` — **화면당 한 번만** |
| 스톤 그레이 | `#6B7672` | 보조 텍스트, 구분선, 비활성 |

**상태 컬러 규칙(3개 제품 공통, 불변)**: 승차 완료·정상 운행 = 그린 / 이동 중·도착 지연 = 앰버 /
미탑승·긴급 = 레드 / 운행 전·종료 = 스톤.

**다크 모드**도 화이트 셸과 같은 원칙입니다 — **면은 중립 잉크, 색은 액션과 상태에만.**
그린을 배경으로 깔지 않습니다(그린 위 그린은 가시성이 무너집니다).
바탕 `#0F1412` / 크롬 `#131917` / 카드 `#181F1D` / 본문 `#EDF2EF`.
**주요 액션은 앰버 `#F5A623`** (글자는 `#1A1206`), 승차 완료·정상은 `#5FD0AC`,
미탑승은 `#F08A7A`. 야간 하원 화면과 매니저 앱(기본 다크)에서 씁니다.

다크는 **명시적 opt-in**입니다 — `data-theme="dark"`가 붙은 요소와 그 안쪽에만 적용됩니다.
매니저 앱은 앱 컨테이너에 이 속성을 붙여 다크를 기본으로 씁니다.
라이트 화면을 확인할 때는 상위 요소에 이 속성이 남아 있지 않은지 먼저 보세요.

### 타입
제목은 **나눔명조**(세리프), 본문·UI·숫자는 **Noto Sans KR**(산세리프). 섞지 않습니다 —
세리프는 아이 이름이 들어간 결론 한 줄과 화면 제목에만.

- 제목 700 / 32–52px / line-height 1.2 / letter-spacing -0.02em
- 본문 400 / 16px / line-height 1.75
- 보조 300 / 13–14px / letter-spacing -0.01em
- UI 라벨 500 / 15px, 시각·호차 700 + `tabular-nums`

### 여백·레이아웃
4px 배수. 카드 내부 20, 카드 사이 12, 섹션 사이 32. 앱 좌우 여백 20px, 웹 32px.
헤더 56 / 탭바 64 / 사이드바 248(좁은 폭 208) / 본문 최대 1160 / 최소 터치 영역 48.
앱은 헤더와 탭바가 **고정**되고 본문만 스크롤합니다. 지도 화면에서는 상단 상태 카드와
하단 시트가 지도 위에 고정으로 겹칩니다.

### 배경
**이미지·일러스트·패턴·그라디언트를 쓰지 않습니다.** 배경은 페이지 틴트(#F4F5F2),
크롬 오프 화이트(#FAFAF7), 카드 흰색, 미스트 그린 네 개의 단색 면뿐입니다.
로그인 화면만 그린 면 + 오프 화이트 시트의 2단 구성입니다 — 브랜드 그린이 크게 나오는 유일한 화면입니다.
지도는 유일한 "이미지성" 영역이고, 실제 SDK 타일이 들어갈 자리입니다
(현재는 `ui_kits/MapSurface.jsx` 플레이스홀더 — 미세한 CSS 격자 + 노선 선).
사진을 넣게 될 경우의 색감 기준: 차갑지 않은 자연광, 저채도, 그레인 없음, 아침 빛.

### 모서리·테두리·카드
카드 16 / 컨트롤 12 / 바텀시트 상단만 24 / 뱃지·pill 999 / 작은 요소 4–8.
카드는 **흰 면 + 낮고 넓은 그린 기반 그림자**이고 테두리는 없습니다.
표·리스트는 그림자 대신 1px `--border-subtle` 구분선만 씁니다.
상태를 강조할 때는 카드 **상단 3px 라인**(`accent`)을 씁니다 —
**왼쪽 컬러 보더 + 라운드 카드 패턴은 이 브랜드에 없습니다.**

### 그림자
검정 그림자를 쓰지 않습니다. 전부 그린 기반(`rgba(18,33,28,…)`)이고 낮고 넓게 퍼집니다.
`--shadow-sm` 구분용 / `--shadow-card` 기본 카드 / `--shadow-raised` 다이얼로그·기기 프레임 /
`--shadow-sheet` 지도 위 바텀시트(위로 뻗는 유일한 그림자). 내부 그림자는 쓰지 않습니다.

### 투명도·블러
**블러(backdrop-filter)를 쓰지 않습니다.** 투명도는 두 곳에만: 그린 배경 위 아이콘 버튼
(`rgba(255,255,255,.14)`), 모달 스크림(`rgba(18,33,28,.48)`, 다크에서는 `rgba(6,13,10,.62)`).
지도 위 요소는 반투명이 아니라 **불투명 카드**로 올립니다 — 정보 가독성이 우선입니다.
보호 그라디언트 대신 **캡슐(불투명 카드)** 방식을 씁니다.

### 애니메이션
짧고 단정하게. **바운스·오버슈트·스프링을 쓰지 않습니다.**
80ms(컬러 토글) / 160ms(호버·프레스·포커스) / 240ms(시트 열기, 화면 전환) / 600ms(지도 카메라,
버스 마커 위치 보간). 이징은 전부 `cubic-bezier(.2,0,.2,1)`.
`prefers-reduced-motion`에서는 전부 1ms로 떨어집니다.
버스 마커는 깜빡이지 않고 위치만 보간합니다.

### 호버·프레스·포커스
- **호버**: 같은 계열을 8% 어둡게(`filter: brightness(.94)`). 색을 바꾸지 않습니다.
- **프레스**: `scale(.985)`만. 색 반전·그림자 제거 없음.
- **포커스**: 2px `--focus-ring` 아웃라인 + 3px 소프트 링. 키보드 사용자에게만(`:focus-visible`).
- **비활성**: opacity 0.42, 커서 not-allowed. 회색으로 다시 칠하지 않습니다.
- **선택된 행**: 미스트 그린 배경. 파란 하이라이트는 쓰지 않습니다.

## ICONOGRAPHY

- **아이콘 자산을 제공받지 못했습니다.** 그래서 **Lucide**(2px stroke, round cap, 24px 그리드)를
  표준으로 채택하고, `components/core/Icon.jsx`가 CDN(`lucide-static@0.428.0`)의 SVG를
  **CSS mask**로 렌더합니다 — 색은 항상 `currentColor`를 따릅니다. **이것은 대체이며, 브랜드
  아이콘 세트를 받으면 Icon 하나만 바꿔 전체가 교체됩니다.**
- 아이콘은 항상 텍스트와 함께. 아이콘만 쓰는 곳은 헤더 액션과 리스트 행의 전화 버튼뿐입니다.
- 크기는 인라인 13–16 / 기본 18–20 / 탭바 24. 굵기를 임의로 바꾸지 않습니다.
- 자주 쓰는 이름: `bus`, `map-pin`, `route`, `navigation`, `bell`, `bell-off`, `users-round`,
  `user-round`, `clock`, `phone`, `check`, `x`, `chevron-right`, `chevron-down`, `search`,
  `settings`, `plus`, `pencil`, `trash-2`, `triangle-alert`, `circle-check`, `circle-alert`,
  `calendar`, `list`, `layout-dashboard`, `house`.
- **이모지는 쓰지 않습니다.** 유니코드 기호도 아이콘으로 쓰지 않습니다.
  구분자로 중간점 `·` 하나만 허용합니다("8:37 · 한화아파트 정류장").
- **로고**: 실제 로고 파일이 없어 `assets/` 에 마크를 두지 않았습니다. 로고 자리에는

#### 의도적으로 추가한 것 (Intentional additions)
출처에 컴포넌트 라이브러리가 없어(기능정의서 + 유저플로우만) 위 목록은 **플로우에 실제로
등장하는 UI만** 골라 만든 것입니다. 그중 출처에 직접 대응이 없지만 필요해서 넣은 것:
- `Icon` — Lucide 글리프 래퍼. 색 상속과 일괄 교체를 위해 필요합니다.
- `CodeInput` — 플로우의 "부여된 코드 입력"을 전용 컨트롤로 만든 것입니다.
- `DelayPicker` — "지연 시간 선택(5분 단위)"을 자유 입력으로 두지 않기 위한 전용 컨트롤입니다.
